# ML Trading Framework

This project is a comprehensive framework for developing and backtesting machine learning-based trading strategies.

## Features

*   Data loading and preprocessing for OHLCVT data.
*   Extensive feature engineering module with a wide range of technical indicators.
*   Support for various machine learning models, from classic models to deep learning architectures.
*   A robust backtesting engine to evaluate strategy performance.
*   Hyperparameter optimization.
*   Modular and extensible design.

## Getting Started

1.  Clone the repository.
2.  Install the dependencies: `pip install -r requirements.txt`
3.  Add your data to the `data/` directory.
4.  Explore the notebooks in the `notebooks/` directory to get started.
